Comment ca marche

1. Vous creez un questionnaire — il demarre en brouillon, invisible pour tous. 2. Vous ajoutez vos questions dans l'editeur. 3. Vous publiez : il devient accessible selon les regles d'acces que vous avez definies.

Une version publiee ne se modifie plus. Pour la corriger, l'editeur cree automatiquement une nouvelle version : les resultats deja obtenus restent intacts.
