Notation

Le bareme de chaque question se regle dans l'onglet Questions. Ici, vous definissez ce qui se passe une fois toutes les questions notees : a partir de quel pourcentage le questionnaire est reussi, et les paliers eventuels.

Ces reglages appartiennent a la version : les modifier n'affecte pas les resultats deja calcules.
