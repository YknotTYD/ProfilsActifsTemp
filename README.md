
# JibJob

Site de recherche de mise en relation entre demandeur et recruteur sous forme de réseau social pour la piscine Survivor de Tech 3


## Deployment

```bash
  docker compose watch
```


## Tech Stack

**Front**: React

**Back**: Django

**Database**: Sqlite
